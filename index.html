一、基本概念

梯度下降（Gradient Descent）是一種最佳化演算法，根據損失函數的梯度調整模型參數，目的是降低 Loss。梯度消失（Vanishing Gradient）則是反向傳播過程中，梯度經過多層傳遞後變得非常小，讓前面幾層的權重難以有效學習。

梯度下降是「神經網路學習的方法」；梯度消失是「可能妨礙學習的現象」。

二、梯度下降的數學原理

1. 從單一神經元開始

假設輸入 \(x=2\)、目標 \(y=10\)，模型與平方誤差損失為：

\[\hat y=wx+b,\qquad L(w)=\frac12(\hat y-y)^2\]

令 \(b=0\)，得：

\[\boxed{L(w)=\frac12(2w-10)^2=2(w-5)^2}\]

最佳權重是 \(w=5\)，此時 \(\hat y=10\) 且損失為零。若不知道答案，便可以用梯度下降尋找它。

2. 梯度與權重更新

導數代表權重微小改變時，Loss 變化的方向與速率。

\[\frac{dL}{dw}=\frac12\cdot2(2w-10)\cdot2=4w-20=4(w-5)\]

梯度下降的核心公式：

\[\boxed{w_{t+1}=w_t-\eta\frac{\partial L}{\partial w_t}}\]

其中 \(\eta\) 是學習率（Learning Rate）。對此範例：

\[\boxed{w_{t+1}=w_t-4\eta(w_t-5)}\]

藍線：\(L(w)=2(w-5)^2\)；橘點：權重更新位置。可測試大於 0.5 的學習率如何造成發散。

4. 梯度下降：五次完整手算

以下逐次計算預測值、誤差、損失、梯度、權重更新。固定輸入 \(x=2\)、目標 \(y=10\)、偏置 \(b=0\)、初始權重 \(w_0=0\)，學習率 \(\eta=0.1\)。

已知公式
\[\begin{aligned}\hat y_t&=2w_t\\e_t&=\hat y_t-10\\L_t&=\tfrac12(\hat y_t-10)^2\\g_t&=\frac{dL}{dw}\bigg|_{w=w_t}=4w_t-20\\w_{t+1}&=w_t-0.1g_t\end{aligned}\]

注意：每次的預測、誤差、梯度使用更新前的權重；更新後 Loss 則以新權重重新計算。

第一次更新（Iteration 1）

更新前權重：\(w_0=0\)。

① 計算預測值

\[\hat y_{0}=w_{0}\times x=0\times2=\boxed{0}\]

② 計算預測誤差

\[e_{0}=\hat y_{0}-y=0-10=\boxed{-10}\]

③ 計算損失 Loss

\[L_{0}=\frac12(0-10)^2=\frac12\times 100=\boxed{50}\]

④ 計算梯度

\[g_{0}=4w_{0}-20=4(0)-20=\boxed{-20}\]

⑤ 使用梯度更新權重

\[w_{1}=w_{0}-0.1g_{0}=0-0.1(-20)=0+2=\boxed{2}\]

第二次更新（Iteration 2）

更新前權重：\(w_1=2\)。

① 計算預測值

\[\hat y_{1}=w_{1}\times x=2\times2=\boxed{4}\]

② 計算預測誤差

\[e_{1}=\hat y_{1}-y=4-10=\boxed{-6}\]

③ 計算損失 Loss

\[L_{1}=\frac12(4-10)^2=\frac12\times 36=\boxed{18}\]

④ 計算梯度

\[g_{1}=4w_{1}-20=4(2)-20=\boxed{-12}\]

⑤ 使用梯度更新權重

\[w_{2}=w_{1}-0.1g_{1}=2-0.1(-12)=2+1.2=\boxed{3.2}\]

第三次更新（Iteration 3）

更新前權重：\(w_2=3.2\)。

① 計算預測值

\[\hat y_{2}=w_{2}\times x=3.2\times2=\boxed{6.4}\]

② 計算預測誤差

\[e_{2}=\hat y_{2}-y=6.4-10=\boxed{-3.6}\]

③ 計算損失 Loss

\[L_{2}=\frac12(6.4-10)^2=\frac12\times 12.96=\boxed{6.48}\]

④ 計算梯度

\[g_{2}=4w_{2}-20=4(3.2)-20=\boxed{-7.2}\]

⑤ 使用梯度更新權重

\[w_{3}=w_{2}-0.1g_{2}=3.2-0.1(-7.2)=3.2+0.72=\boxed{3.92}\]

第四次更新（Iteration 4）

更新前權重：\(w_3=3.92\)。

① 計算預測值

\[\hat y_{3}=w_{3}\times x=3.92\times2=\boxed{7.84}\]

② 計算預測誤差

\[e_{3}=\hat y_{3}-y=7.84-10=\boxed{-2.16}\]

③ 計算損失 Loss

\[L_{3}=\frac12(7.84-10)^2=\frac12\times 4.6656=\boxed{2.3328}\]

④ 計算梯度

\[g_{3}=4w_{3}-20=4(3.92)-20=\boxed{-4.32}\]

⑤ 使用梯度更新權重

\[w_{4}=w_{3}-0.1g_{3}=3.92-0.1(-4.32)=3.92+0.432=\boxed{4.352}\]

第五次更新（Iteration 5）

更新前權重：\(w_4=4.352\)。

① 計算預測值

\[\hat y_{4}=w_{4}\times x=4.352\times2=\boxed{8.704}\]

② 計算預測誤差

\[e_{4}=\hat y_{4}-y=8.704-10=\boxed{-1.296}\]

③ 計算損失 Loss

\[L_{4}=\frac12(8.704-10)^2=\frac12\times 1.679616=\boxed{0.839808}\]

④ 計算梯度

\[g_{4}=4w_{4}-20=4(4.352)-20=\boxed{-2.592}\]

⑤ 使用梯度更新權重

\[w_{5}=w_{4}-0.1g_{4}=4.352-0.1(-2.592)=4.352+0.2592=\boxed{4.6112}\]

第五次更新完成後，再計算新的 Loss

\[\begin{aligned}\hat y_5&=4.6112\times2=9.2224\\e_5&=9.2224-10=-0.7776\\L_5&=\frac12(-0.7776)^2=\boxed{0.30233088}\end{aligned}\]

為什麼權重更新量逐步減少？

\[\begin{aligned}\Delta w_1&=2\\\Delta w_2&=1.2\\\Delta w_3&=0.72\\\Delta w_4&=0.432\\\Delta w_5&=0.2592\end{aligned}\]

由更新式可得：

\[\begin{aligned}w_{t+1}&=w_t-0.1(4w_t-20)\\&=0.6w_t+2\end{aligned}\]

因此可推導出封閉形式：

\[\boxed{w_n=5(1-0.6^n)},\qquad\boxed{L_n=50(0.6)^{2n}}\]
\[L_{n+1}=0.36L_n\]

本例每更新一次，Loss 剩下前一次的 36%，也就是下降 64%。權重逐漸接近最佳值 \(w=5\)，因此梯度與權重更新量也同步縮小。

教學重點：此例梯度變小是因為模型逐漸接近最佳解；它與深層網路反向傳播中的「梯度消失」問題不同。

三、學習率對收斂的影響

學習率太小會收斂緩慢；適中通常可快速穩定逼近低損失區域；太大可能震盪甚至發散。

對本例，有：

\[w_{t+1}-5=(1-4\eta)(w_t-5)\]

要讓誤差大小持續縮小：

\[|1-4\eta|<1\quad\Longrightarrow\quad\boxed{0<\eta<0.5}\]
這是針對本例二次函數的收斂條件，不是所有神經網路的通用學習率範圍。

四、前向傳播、反向傳播與梯度下降

  1. 前向傳播（Forward Propagation）：利用目前權重算出 \(\hat y\) 和 Loss。
  2. 反向傳播（Backpropagation）：透過鏈式法則計算各層參數的梯度。
  3. 梯度下降（Gradient Descent）：使用計算好的梯度更新權重與偏置。
反向傳播負責計算梯度；最佳化器根據梯度更新參數。

五、梯度消失與多種激活函數

神經元的運算為：

\[z=wx+b,\qquad a=f(z)\]

不同激活函數的形狀與導數，會直接影響反向傳播時梯度是否容易衰減。請從下方選擇函數，比較 函數曲線 與 導數曲線。

教學觀察

    核心觀念： 梯度消失通常不是因為輸出值本身小，而是因為反向傳播時，每一層都乘上一個很小的導數，讓前面層接收到的梯度越來越小。

    六、鏈式法則：為何梯度越傳越小

    考慮四層網路 \(x\to a_1\to a_2\to a_3\to a_4\)，各層為 \(a_i=\sigma(w_i a_{i-1}+b_i)\)。第一層權重的梯度為：

    \[\boxed{\frac{\partial L}{\partial w_1}=\frac{\partial L}{\partial a_4}\frac{\partial a_4}{\partial a_3}\frac{\partial a_3}{\partial a_2}\frac{\partial a_2}{\partial a_1}\frac{\partial a_1}{\partial w_1}}\]

    其中：

    \[\frac{\partial a_i}{\partial a_{i-1}}=w_i\sigma'(z_i)\]

    所以：

    \[\frac{\partial L}{\partial w_1}=\frac{\partial L}{\partial a_4}\left(\prod_{i=2}^{4}w_i\sigma'(z_i)\right)\sigma'(z_1)x\]

    若權重為 1、每一層的 Sigmoid 導數為 0.25、輸入與輸出端梯度尺度均取 1，則：

    \[0.25^4=0.00390625\qquad\text{與}\qquad0.25^{10}\approx9.54\times10^{-7}\]

    這裡是為了說明機制而設定的簡化標量例子；真實深層網路還會受到權重矩陣、激活函數及梯度路徑影響。

    七、梯度消失造成的問題

    現象影響
    早期層梯度很小前段特徵提取層更新緩慢
    權重幾乎不變訓練可能長時間停滯
    Loss 下降緩慢模型學習效率偏低
    深層網路難以充分訓練增加深度不一定帶來效益
    RNN 長序列梯度衰減長距離依賴難以學習

    輸出端附近的層可能仍能學習，但距離輸出較遠的早期層容易受影響。

    八、不同激活函數的梯度特性

    Sigmoid

    \[f(x)=\frac1{1+e^{-x}},\quad f'(x)=f(x)(1-f(x))\]

    Tanh

    \[f(x)=\tanh(x),\quad f'(x)=1-\tanh^2(x)\]

    零附近導數最大為 1，但遠離零時仍會飽和。

    ReLU

    \[\boxed{f(x)=\max(0,x)},\quad f'(x)=\begin{cases}0,&x<0\\1,&x>0\end{cases}\]

    ReLU 在 \(x=0\) 不可微，實作時可指定次梯度。正半軸導數為 1，減少激活函數本身帶來的梯度衰減；負半軸導數為零可能造成 Dying ReLU。

    藍：Sigmoid′；橘：Tanh′；綠：ReLU′（零點顯示為 0，為一種實作約定）。

    激活函數梯度消失風險主要注意事項
    Sigmoid高最大導數 0.25；兩端飽和
    Tanh中至高兩端飽和
    ReLU相對較低負半軸梯度零
    Leaky ReLU相對較低負半軸保留小斜率
    GELU視模型而定平滑非線性

    九、解決梯度消失的方法

    1. 適當的激活函數

    深層 MLP/CNN 可考慮 ReLU、Leaky ReLU、GELU 等。

    import torch.nn as nn
model = nn.Sequential(
    nn.Linear(10, 64), nn.ReLU(),
    nn.Linear(64, 64), nn.ReLU(),
    nn.Linear(64, 1)
)

    2. 合適的權重初始化

    Xavier/Glorot 常用於 Tanh 或線性層；He/Kaiming 常用於 ReLU 類型；Orthogonal 在某些深層與循環網路有幫助。

    \[\operatorname{Var}(W)\approx\frac{2}{n_{\mathrm{in}}}\]

    3. 殘差連接（Residual Connection）

    一般網路為 \(y=F(x)\)，殘差網路為：

    \[\boxed{y=F(x)+x}\]

    對輸入求導：

    \[\frac{\partial y}{\partial x}=\frac{\partial F(x)}{\partial x}+1\]

    多維情況下，額外的恆等映射對應單位矩陣 \(I\)。這有助於梯度傳遞，但不保證所有情況都不會消失。

    4. 正規化

    Batch Normalization 與 Layer Normalization 可協助控制中間特徵尺度與訓練穩定性，但不是萬能解法。

    5. LSTM 或 GRU

    傳統 RNN 容易在長序列反向傳播時梯度消失；LSTM/GRU 透過門控改善長期資訊流動。

    十、PyTorch：量測各層梯度大小

    下面的範例可以直接在 Google Colab 執行。以單位矩陣初始化 10 層 Sigmoid，使梯度衰減現象容易觀察。

    import torch
import torch.nn as nn

torch.manual_seed(42)
model = nn.Sequential(
    *[layer for _ in range(10)
      for layer in (nn.Linear(16, 16, bias=False),
                    nn.Sigmoid())]
)

for layer in model:
    if isinstance(layer, nn.Linear):
        nn.init.eye_(layer.weight)

x = torch.ones(1, 16) * 0.1
loss = model(x).sum()
loss.backward()

for i, layer in enumerate(model):
    if isinstance(layer, nn.Linear):
        grad = layer.weight.grad.norm().item()
        print(f"Layer {i//2+1:2d}: Gradient norm = {grad:.9e}")

    loss.backward() 執行反向傳播；layer.weight.grad.norm() 是該層梯度張量的 L2 範數。實際判讀時也應觀察 Loss、梯度與權重的比例、訓練及驗證指標。

    十二、常見疑問與總結

    梯度下降等於梯度變小嗎？

    不是。下降指的是期望 Loss 變小，並不是要求梯度值一直變小。

    梯度接近零就表示訓練成功嗎？

    不是。可能是極小值，也可能是鞍點、平坦區或激活函數飽和。

    加大學習率就能解決梯度消失嗎？

    不一定。學習率放大更新量，但無法從根本改善反向梯度衰減；過大還會不穩定。

    ReLU 一定沒有梯度消失嗎？

    不是。梯度仍會受到權重矩陣及其他運算影響，ReLU 負半軸導數也為零。

    核心公式一：梯度下降
    \[\boxed{w_{t+1}=w_t-\eta\frac{\partial L}{\partial w_t}}\]
    核心公式二：梯度傳播連乘
    \[\boxed{\frac{\partial L}{\partial w}\propto\prod_{i=1}^{n}g_i}\]

    若每層倍率持續小於 1，乘積就可能快速趨近零。
